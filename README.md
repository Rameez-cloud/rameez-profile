# Rameezraja Mulla — Cloud Architect Profile

Online profile and resume site built from LinkedIn data, hosted on GitHub Pages.

## Sections

- Hero with key stats
- About
- Skills & specializations
- Experience timeline (Deloitte, Kroll, Capgemini)
- Impact metrics
- Contact links

## Tech

Plain HTML, CSS, and vanilla JS — no build step required.

## Local preview

```bash
# from the repo root
python -m http.server 8000
```

Open http://localhost:8000

## Deploy

Pushed to GitHub Pages via the `main` branch (root). See repo settings → Pages.
